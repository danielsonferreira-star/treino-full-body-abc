# Full Body ABC

App de treino full body (A, B, C) com calendário do ciclo, registro de cargas, envio ao Strava e atalho para o app Saúde do iPhone.

- `index.html` e `integracoes.js` — página publicada pelo Netlify
- `netlify/functions/strava.mjs` — ponte com o Strava (usa as variáveis `STRAVA_CLIENT_ID` e `STRAVA_CLIENT_SECRET`)
